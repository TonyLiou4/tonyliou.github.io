# tonyliou.github.io

Personal website for **Tony Liou** — Computer Science graduate student at The Ohio State University and Data Analyst Intern at PNC.

Built as a single-page, Apple-inspired site: system typography, generous whitespace, translucent sticky navigation, subtle scroll-reveal animations, and full light/dark + reduced-motion support. No build step, no dependencies.

**Live:** https://tonyliou4.github.io/tonyliou.github.io/

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Page content and structure |
| `styles.css` | All styling and responsive/theme rules |
| `script.js` | Sticky-nav, mobile menu, scroll reveals |
| `.nojekyll` | Serve files as static assets (bypass Jekyll) |

## Editing

Open `index.html` to edit content, `styles.css` for design. Commit and push to `main` — GitHub Pages redeploys automatically within a minute or two.
